# Recommender Calendar

명지대학교 정보통신공학과 캡스톤디자인 프로젝트

## 프로젝트 소개

사용자의 관심 분야를 기반으로 채용정보 및 관련 자격증을 추천하고,
채용 마감일과 자격증 시험일을 바탕으로 취업 및 학습 준비 일정을
관리할 수 있는 캘린더 서비스입니다.

## 주요 기능

- 관심 분야 설정
- 채용정보 추천
- 자격증 추천
- 채용 마감일 및 시험일 관리
- 캘린더 기반 일정 관리
- 취업 및 학습 준비 일정 추천

## 개발 목적

캡스톤디자인 프로젝트를 통해 채용정보와 자격증 정보를 활용한
취업 준비 지원 서비스를 구현하고 AWS 기반의 웹 서비스 운영을 경험하는 것을 목표로 합니다.
